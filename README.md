# Gazi Meclis-i Mebusan

Bu klasör GitHub Pages ile yayınlamak için hazırlandı.

## GitHub Pages kurulumu

1. Bu klasördeki tüm dosyaları GitHub deposuna yükleyin.
2. GitHub üzerinde repository ayarlarından Pages bölümüne gidin.
3. Source olarak "Deploy from a branch" seçin.
4. Branch olarak `main` ve folder olarak `/root` seçin.
5. Kaydettiğinizde site yayınlanmaya başlar.

## Alan adı (custom domain)

Hostinger DNS ayarlarında aşağıdaki kayıtları ekleyin:

- `A` kayıtları:
  - 185.199.108.153
  - 185.199.109.153
  - 185.199.110.153
  - 185.199.111.153

- `CNAME` kayıt:
  - `www` → `yavuzselimterzi-ctrl.github.io`

GitHub Pages ayarlarında ise Custom domain olarak:

- `gazimeclis.com`

ekleyin.
